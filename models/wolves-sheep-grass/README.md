# Wolves-Sheep-Grass

Explores the interactions between three species in an ecosystem (wolves, sheep, and grass), a classic predator-prey-resource dynamics model.

## Try it
- [Run in your browser](app.html) (NetLogo Web export, self-contained HTML)
- [`model.nlogo`](model.nlogo) — open in the desktop [NetLogo](https://ccl.northwestern.edu/netlogo/) application to edit

## Metadata
- **Concepts:** Predator-prey dynamics, Ecosystem dynamics, Population cycles
- **Subject areas:** Biology, Computer Science, STEM
- **Grade levels:** 6-8, 9-12, Teacher education
- **Material types:** Computer Model
