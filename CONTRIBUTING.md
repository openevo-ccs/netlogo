# Contributing to the OpenEvo NetLogo collection

## Before you start

Read [`README.md`](README.md) for the repo's layout and [`lpm-strands/README.md`](lpm-strands/README.md)
for how Learning Progression Map (LPM) strands are developed. Every strand currently in this repo
is an unvalidated AI-synthesized draft — see that file's own disclaimer before treating any strand
as vetted curriculum.

## Adding or updating a model

Each model lives in `models/<slug>/` and needs the full set described in `README.md`'s "What's
here" section: `app.html` (NetLogo Web export), `model.nlogo` (source), `<slug>.nlogox` (NetLogo 7
XML), `model-card.json` + `agent-manifest.json` (generated by `netlogo-agent-toolkit/` — see its
own README), `metadata.json`, and `README.md`. Then register the model in `assets/models.json` (the
explorer's index) so it's browsable.

If the model is redistributed from OpenEvo TeachingBase, it's CC BY-SA like the rest of the
collection; if it's sourced elsewhere (e.g. the official NetLogo Models Library), keep its own
license and say so explicitly in both `assets/models.json` (`license`/`licenseNote` fields) and the
model's own `README.md` — see `models/beesmart-hive-finding/README.md` for the pattern.

## Developing an LPM strand

Follow the 5-step process in [`lpm-strands/README.md`](lpm-strands/README.md). A strand isn't
"done" until step 5 (a schema-validated `oe:Strand` contribution, validated via ConceptBase's
`conceptbase_validate_entry`) is complete — narrative-only drafts should keep the draft-concept
disclaimer and an honest "Schema-Ready Contribution: not done" status rather than implying
completeness.

## Explorer app changes

The GitHub Pages explorer (`index.html` + `assets/`) is plain HTML/CSS/vanilla JS — no build step,
no framework. Keep it that way; new features should extend the existing module pattern (one
`<script>` per concern: `app.js`, `graph-explorer.js`, `model-bridge.js`, etc.) rather than adding a
build tool for a static site this size.

## Pull requests

Open a PR against `main` with a clear description of what changed and why. There's no CI pipeline
yet, so manually verify the explorer still loads and the model(s) you touched still run before
requesting review.

## Questions

Open a [GitHub issue](../../issues) or reach out to the OpenEvo Computational Curriculum Studies
Lab ([openevo.eva.mpg.de](http://openevo.eva.mpg.de)).
