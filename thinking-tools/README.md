# Thinking Tools for NetLogo Models

This directory contains interactive thinking tool templates that can be used alongside NetLogo models to deepen student understanding.

## What are Thinking Tools?

OpenEvo's six thinking tools are cognitive scaffolds that help students:

- Structure their thinking about complex phenomena
- Make connections across different models and concepts
- Develop integrated causal reasoning
- Engage in metacognitive reflection

## The Six Thinking Tools

### 1. Tinbergen's Questions
Four questions that provide a comprehensive framework for understanding any behavior:
- **Function**: What problem does this behavior solve?
- **Mechanism**: How does the behavior work?
- **Development**: How does the behavior develop?
- **Evolution**: How did the behavior evolve?

### 2. Causal Mapping
Visual diagrams that show cause-effect relationships and feedback loops in complex systems.

### 3. Payoff Matrices
Tables that show the costs and benefits of different choices in strategic interactions.

### 4. The Noticing Tool
Guided reflection prompts that help students observe patterns and surprises.

### 5. Analogies & Analogy Mapping
Structured comparison of similar phenomena across different contexts.

### 6. Structure of Knowledge Diagrams
Visual representations of how concepts connect and build on each other.

## Using These Tools

Each thinking tool has:
- A template file (HTML/JS for interactive use)
- A guide explaining when and how to use it
- Example applications for specific models

## Integration with Models

Thinking tools can be:
- Embedded in the model explorer interface
- Used as standalone activities
- Integrated into lesson plans
- Used for assessment and reflection

## Contributing

When adding thinking tool examples:

1. Follow the existing template structure
2. Provide clear instructions for students
3. Include model-specific prompts and examples
4. Connect to relevant competencies from ConceptBase
5. Test with actual students when possible
