# Assessments for NetLogo Models

This directory contains integrated-causal-reasoning assessment item banks for each NetLogo model, following the EvoFlex pattern (Hanisch, Eirdosh, González Galli, Hartelt, Pérez & Cupo, 2025).

## Assessment Structure

Each assessment file (`<model-slug>.json`) contains:

- **Vignette**: A scenario describing the model's phenomenon
- **Items**: Multiple-choice questions diagnosing integrated vs. dichotomized reasoning
- **Scoring**: Rubric mapping responses to reasoning patterns
- **Competencies**: Links to OECB competencies being assessed

## Assessment Pattern

Assessments follow the integrated-causal-reasoning pattern:
- **Integrated reasoning**: Recognizes multiple interacting mechanisms, agency, and context-dependence
- **Dichotomized reasoning**: Reduces complex phenomena to single causes, ignores agency, or assumes fixed outcomes

## Usage

Assessments can be:
- Embedded in the model explorer interface
- Used as standalone formative assessments
- Integrated into lesson plans
- Used for research on student reasoning
